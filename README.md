# Lab: Document Intelligence no Azure

Projeto desenvolvido durante o **Bootcamp da DIO - Microsoft Certification Challenge #5 - AI 102**.  
Este lab demonstra como utilizar o serviço **Azure Document Intelligence** para validar documentos e detectar possíveis fraudes, integrando recursos de armazenamento e processamento inteligente.

---

## 📖 Descrição
O objetivo do lab foi criar um **grupo de recursos no Azure**, provisionar um recurso de **Document Intelligence** e configurar uma **conta de armazenamento**.  
Com isso, foi possível testar na prática como o Azure aplica inteligência artificial para analisar documentos e identificar inconsistências.

## 🚀 Tecnologias utilizadas
- Azure Document Intelligence
- Azure Storage Account
- Python (scripts de integração)
- Azure Portal

## ⚙️ Funcionalidades demonstradas
- Criação de grupo de recursos no Azure
- Provisionamento do serviço Document Intelligence
- Configuração de conta de armazenamento
- Validação de documentos e detecção de fraudes

## 📂 Estrutura do repositório
- `README.md` → este arquivo
- `codigo/` → scripts de exemplo utilizados no lab (sem chaves ou endpoints sensíveis)

## 📝 Observação
Os arquivos de código foram ajustados para **não incluir chaves ou endpoints**.  
Essas informações devem ser configuradas diretamente no ambiente do Azure.

## 🎯 Objetivo
Demonstrar na prática como o **Azure Document Intelligence** pode ser usado para validar documentos e apoiar processos de detecção de fraudes.
